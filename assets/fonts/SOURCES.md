# Resource Han Rounded CN Regular

- Author: Cyano Hao; based on Adobe Source Han Sans.
- Official project: https://github.com/CyanoHao/Resource-Han-Rounded
- Source release: 0.990, https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990
- Original file: ResourceHanRoundedCN-Regular.ttf (14,663,464 bytes).
- Original SHA-256: 1c5c623f008eabef10c45135a48b01b46311f9369c28857355872cfe05f48dc0
- License: SIL Open Font License 1.1; see `Resource-Han-Rounded-OFL.txt`.
- Prepared: 2026-10-13, using FontTools and Brotli compression.

The two WOFF2 subsets preserve the original glyph outlines and font metadata.
`resource-han-rounded-cn-regular-site.woff2` covers every Chinese character and supported non-Latin symbol in the current website, including switch labels.
`resource-han-rounded-cn-regular-other.woff2` covers the remaining supported non-Latin characters so future Chinese content has the same font.
The CSS Unicode ranges are disjoint, so current pages only download the small site subset.
Latin text continues to use Jost. All fonts are served from this website.

如果你想做AI相关的工作，不妨考虑一下Agent Infra这个新兴领域。我最近也在入门这个领域，做了一些调研，记录了这个领域需要的技能清单，欢迎收藏，保存，我也会继续分享在这个领域的学习心得。

完整 List：
1.Agent Runtime：理解 Agent Loop、Tool Calling、Streaming、Session，理解并实现一个最小可用Agent，而不是只调用一次模型 API。
2.上下文与状态管理：喂给大模型的上下文决定了这一轮模型能看到什么，也很大程度上决定模型做的决策质量；State 会保存任务当前执行到了哪里。需要处理上下文裁剪、压缩、Checkpoint、任务状态，长期记忆与短期上下文。
3.任务队列与 Worker：把任务通过 Queue 分发给 Worker 执行，并控制并发、优先级、Backpressure 和 Worker Pool。
4.调度与多 Agent 编排：把复杂任务拆成多个子任务，支持DAG、Reviewer、Handoff 和 Human-in-the-loop。
5.Durable Execution：Agent 即使运行几十分钟甚至几个小时后，也不会因为进程重启而导致任务的丢失，需要持久化执行状态、Checkpoint、Replay、Resume 和 Recovery。
6.Retry、Timeout 与幂等：模型、工具、网络和 Worker 等各方面都会遇到问题；系统要能判断什么时候重试、什么时候超时，以及避免 git push、发邮件、创建资源等操作被重复执行。
7.分布式状态与一致性：多个 Orchestrator、Worker 和数据库共同维护 Task State，需要理解 Transaction、WAL、Lease、Heartbeat、Replication、Consistency 以及故障恢复。
8.Sandbox 与执行环境：Coding Agent 会执行 Shell、Git、Python、构建和测试，需要为每个 Agent 提供隔离的文件系统、进程、网络和资源环境，并限制 CPU、内存和执行时间。
9.工具基础设施与 MCP：Agent 不只是调用几个 Function，还需要统一管理 Shell、Filesystem、Browser、Database、API 等工具；MCP 可以作为 Agent 与外部工具、资源之间的一种标准接口。
10.权限、安全与 Secrets：控制 Agent 能访问哪些文件、调用哪些工具、连接哪些网络和读取哪些密钥，涉及 Authentication、Authorization、ACL、Secret Management 和 Audit。
11.可观测性与调试：Agent Task 的完整执行过程会通过trace记录下来，用 Metrics 看延迟、Queue、Token、成本、失败率和 Retry。
12.Evaluation 与 Replay：不只看“Agent 能不能跑”，还要判断任务是否真的完成正确，通过 Dataset、Rubric、Task Success Rate、Regression、Replay 和 LLM-as-Judge 做持续评估。

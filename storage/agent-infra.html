Agent Infra

从原始笔记整理的 12 项技能清单。

运行与编排

  • Agent Runtime

    理解 Agent Loop、Tool Calling、Streaming 和 Session；实现一个能够循环执行任务的最小 Agent。

  • 上下文与状态管理

    区分模型当前能看到的上下文与任务执行状态。处理上下文裁剪、压缩、Checkpoint，以及短期上下文和长期记忆。

  • 任务队列与 Worker

    通过 Queue 分发任务，控制并发、优先级、Backpressure 和 Worker Pool。

  • 调度与多 Agent 编排

    拆分复杂任务，组织 DAG、Reviewer、Handoff 和 Human-in-the-loop。

可靠性与一致性

  • Durable Execution

    持久化执行状态，通过 Checkpoint、Replay、Resume 和 Recovery，在进程重启后恢复长任务。

  • Retry、Timeout 与幂等

    为模型、工具、网络和 Worker 的失败设置重试与超时，避免推送代码、发邮件、创建资源等操作重复执行。

  • 分布式状态与一致性

    理解 Transaction、WAL、Lease、Heartbeat、Replication、Consistency 与故障恢复，协调 Orchestrator、Worker 和数据库的任务状态。

工具、隔离与权限

  • Sandbox 与执行环境

    为 Agent 隔离文件系统、进程、网络与资源，限制 CPU、内存和执行时间。

  • 工具基础设施与 MCP

    统一管理 Shell、Filesystem、Browser、Database 和 API 等工具；理解 MCP 作为工具与资源接口的作用。

  • 权限、安全与 Secrets

    控制文件、工具、网络与密钥访问，理解 Authentication、Authorization、ACL、Secret Management 和 Audit。

观测与评估

  • 可观测性与调试

    用 Trace 记录完整执行过程，用 Metrics 观察延迟、队列、Token、成本、失败率和重试。

  • Evaluation 与 Replay

    通过 Dataset、Rubric、Task Success Rate、Regression、Replay 和 LLM-as-Judge 持续评估任务结果。
